# codegen 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the codegen skill produce accessible, convention-locked React/Next components (required semantic `--element`, `--variants`, `--as-child`), add a `form-field` generator, fail clearly on missing requirements, and add behavior evals.

**Architecture:** The zero-dependency engine (`scripts/lib/generate.mjs`) gains three generic pack.json features: `required`/`choices` on options, `requires` (npm packages) on generators and options, and `requiresUi` (shadcn primitives) on generators. Flag-combination logic for components lives in a new `lib/elements.mjs`, which computes TSX snippets so templates stay readable. Evals are a separate `evals/` folder (fixture app + runner) that is never shipped to repos.

**Tech Stack:** Node ≥ 20 ESM, `node:test`, no npm dependencies. Generated code: TypeScript, React 19 / Next 15, Tailwind v4, shadcn/ui, class-variance-authority, Radix Slot, react-hook-form + zod.

**Spec:** `docs/superpowers/specs/2026-10-12-codegen-0.2.0-design.md`

## Global Constraints

- Node ≥ 20; **zero npm dependencies** in the skill, the tests and the evals (only `node:*` built-ins).
- Generator output is always JSON on stdout; it never overwrites; writes are all-or-nothing.
- Generated files: kebab-case names, named exports only (framework-required defaults excepted), no `React.FC`.
- `--element` allowlist, verbatim: `div, span, section, article, aside, nav, header, footer, main, ul, ol, li, button, a, form, label, p, h1, h2, h3, h4, h5, h6`.
- Missing-requirement error shape: `{ ok: false, error, missing: string[], missingUi: string[], install: string }`, and nothing is written.
- Tests stay optional (`--with-test`), runner auto-detected.
- Supported agents: Claude Code, Cursor, GitHub Copilot.
- Release version: `0.2.0`.
- Paths below are relative to the repo root; `SKILL=.agents/skills/codegen`.

## Review Focus

1. **Every flag combination yields consistent TSX.** `Comp` is declared if and only if it's used, `type` is never forced onto a Slot child, and opening and closing tags match. Pinned by the combinatorial test in Task 4.
2. **A 0.1.0 repo override of `component.tsx.tpl` keeps working.** The override doesn't know the new variables, but generation must still succeed (with `--element`) and use the override. Pinned in Task 4.
3. **`--element` passed without a value** (`--element --variants`) gives "`--element needs a value`", not a crash. Pinned in Task 1 (engine) and Task 4 (CLI).
4. **Monorepo with the lockfile in a parent folder.** The install hint must use that folder's package manager (`pnpm add`, not `npm i`). Pinned in Task 1.
5. **`src/` repo whose shadcn alias is `@/components/ui`.** `requiresUi` must look in `src/components/ui`, and imports must stay `@/components/ui/...`. Pinned in Task 2 and Task 5.

```js
const here = path.dirname(fileURLToPath(import.meta.url));
export const skillDir = path.join(here, '..', '.agents', 'skills', 'codegen');
export const cli = path.join(skillDir, 'scripts', 'generate.mjs');

export function makeRepo({ deps = {}, dirs = [], files = {} } = {}) {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), 'codegen-'));
  fs.writeFileSync(path.join(root, 'package.json'), JSON.stringify({ devDependencies: deps }));
  for (const d of dirs) fs.mkdirSync(path.join(root, d), { recursive: true });
  for (const [p, c] of Object.entries(files)) {
    fs.mkdirSync(path.dirname(path.join(root, p)), { recursive: true });
    fs.writeFileSync(path.join(root, p), c);
  }
  return root;
}

// A throwaway skill with one pack "t" and one generator "g", for engine tests.
export function makeSkill({ template = 'x', ...generator } = {}) {
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'codegen-skill-'));
  fs.mkdirSync(path.join(dir, 'packs', 't', 'templates'), { recursive: true });
  fs.writeFileSync(path.join(dir, 'packs', 't', 'templates', 'x.tpl'), template);
  const g = { out: 'out', options: {}, files: [{ template: 'x.tpl', path: '{{name.kebab}}.ts' }], ...generator };
  fs.writeFileSync(path.join(dir, 'packs', 't', 'pack.json'), JSON.stringify({ vars: {}, generators: { g } }));
  return dir;
}

export function run(root, ...args) {
  const r = spawnSync(process.execPath, [cli, ...args], { cwd: root, encoding: 'utf8' });
  try {
    return { status: r.status, json: JSON.parse(r.stdout) };
  } catch {
    throw new Error(`Non-JSON output (exit ${r.status}):\n${r.stdout}\n${r.stderr}`);
  }
}

export const read = (root, p) => fs.readFileSync(path.join(root, p), 'utf8');
```

```js
import fs from 'node:fs';
import path from 'node:path';

import { allDeps } from './detect.mjs';

// "a|b" is satisfied by either package; the first one is the suggestion.
export function missingDependencies(pkg, requires) {
  const deps = allDeps(pkg);
  const missing = requires.filter((req) => !req.split('|').some((name) => deps[name])).map((req) => req.split('|')[0]);
  return [...new Set(missing)];
}

const LOCKFILES = [
  ['pnpm-lock.yaml', 'pnpm add'],
  ['yarn.lock', 'yarn add'],
  ['bun.lock', 'bun add'],
  ['bun.lockb', 'bun add'],
  ['package-lock.json', 'npm i'],
];

// Walks up from the app root so monorepo workspaces use the workspace's package manager.
export function installCommand(root, packages) {
  for (let dir = path.resolve(root); ; dir = path.dirname(dir)) {
    const found = LOCKFILES.find(([file]) => fs.existsSync(path.join(dir, file)));
    if (found) return `${found[1]} ${packages.join(' ')}`;
    if (path.dirname(dir) === dir) return `npm i ${packages.join(' ')}`;
  }
}
```

```js
// shadcn's components.json is the source of truth for import aliases.
export function detectShadcnAliases(root) {
  try {
    const { aliases = {} } = JSON.parse(fs.readFileSync(path.join(root, 'components.json'), 'utf8'));
    return { utils: aliases.utils ?? null, ui: aliases.ui ?? null };
  } catch {
    return { utils: null, ui: null };
  }
}

const CN_EXPORT = /export\s+(?:function\s+cn\b|const\s+cn\s*=)/;

// Without components.json, look for cn() where shadcn puts it and assume the default @/ alias.
export function detectCn(root) {
  const { utils } = detectShadcnAliases(root);
  if (utils) return utils;
  for (const dir of ['lib', 'src/lib']) {
    for (const ext of ['ts', 'tsx', 'js']) {
      const file = path.join(root, dir, `utils.${ext}`);
      if (fs.existsSync(file) && CN_EXPORT.test(fs.readFileSync(file, 'utf8'))) return '@/lib/utils';
    }
  }
  return null;
}

export function detectSlot(pkg) {
  const deps = allDeps(pkg);
  if (deps['@radix-ui/react-slot']) return { import: '@radix-ui/react-slot', component: 'Slot' };
  if (deps['radix-ui']) return { import: 'radix-ui', component: 'Slot.Root' };
  return null;
}

// '@/components/ui' -> 'components/ui' or 'src/components/ui', following the repo's src/ convention.
export function resolveAliasDir(root, alias) {
  return resolveOut(root, alias.replace(/^[@~]\//, '')).split(path.sep).join('/');
}
```

```js
// Derived TSX snippets for the component template. Keeping the flag logic here
// keeps the template readable and guarantees every flag combination is valid TSX.

const NO_SEMANTICS =
  'div/span carry no meaning: if this is interactive use button or a; if it is a page region use section, nav, aside, header or footer';
const HEADING = 'keep heading levels sequential on the page (one h1 per page)';
const LIST = 'render only li children';

const A11Y_NOTES = {
  div: NO_SEMANTICS,
  span: NO_SEMANTICS,
  section: 'name the section with aria-labelledby pointing at its heading; unnamed sections are not landmarks',
  nav: 'name the nav with aria-label (e.g. "Footer") so screen readers can tell navs apart',
  main: 'render only one main per page',
  ul: LIST,
  ol: LIST,
  button: 'icon-only buttons need an aria-label; use the disabled attribute for the disabled state',
  a: 'use the router link for internal routes (next/link in Next) and keep the link text meaningful out of context',
  form: 'label every control and handle submit with a server action or the form library',
  label: 'associate the label with its control via htmlFor (or by wrapping it)',
  h1: HEADING,
  h2: HEADING,
  h3: HEADING,
  h4: HEADING,
  h5: HEADING,
  h6: HEADING,
};

export function elementVars({ element, name, variants, asChild, cn }) {
  const isButton = element === 'button';
  const variantsFn = `${name.camel}Variants`;
  const base = element === 'a' ? "Omit<ComponentProps<'a'>, 'href'> & { href: string }" : `ComponentProps<'${element}'>`;

  let classNameAttr = 'className={className}';
  if (variants && cn) classNameAttr = `className={cn(${variantsFn}({ variant, size }), className)}`;
  else if (variants) classNameAttr = `className={${variantsFn}({ variant, size, className })}`;
  else if (cn) classNameAttr = "className={cn('', className)}";

  return {
    tag: asChild ? 'Comp' : element,
    propsType: [base, variants && `VariantProps<typeof ${variantsFn}>`, asChild && '{ asChild?: boolean }'].filter(Boolean).join(' & '),
    params: ['className', variants && 'variant', variants && 'size', asChild && 'asChild = false', isButton && "type = 'button'", 'children', '...props']
      .filter(Boolean)
      .join(', '),
    classNameAttr,
    typeAttr: !isButton ? '' : asChild ? ' type={asChild ? undefined : type}' : ' type={type}',
    a11yNote: A11Y_NOTES[element] ?? '',
    testProps: element === 'a' ? ' href="/"' : '',
  };
}
```

```js
import fs from 'node:fs';
import path from 'node:path';

const SKIPPED = new Set(['node_modules', '.git', '.agents', '.claude', '.github']);

export function listFiles(root, dir = '') {
  return fs
    .readdirSync(path.join(root, dir), { withFileTypes: true })
    .filter((entry) => !SKIPPED.has(entry.name))
    .flatMap((entry) => {
      const rel = dir ? `${dir}/${entry.name}` : entry.name;
      return entry.isDirectory() ? listFiles(root, rel) : [rel];
    })
    .sort();
}

// claude -p --output-format stream-json: one JSON message per line.
export function generatorCalls(streamJson) {
  return streamJson.split('\n').flatMap((line) => {
    let msg;
    try {
      msg = JSON.parse(line);
    } catch {
      return [];
    }
    if (msg.type !== 'assistant') return [];
    return (msg.message?.content ?? [])
      .filter((block) => block.type === 'tool_use' && block.name === 'Bash' && /generate\.mjs/.test(block.input?.command ?? ''))
      .map((block) => block.input.command);
  });
}

export function evaluateCase(def, { newFiles, commands, read, tokensOk }) {
  const failures = [];
  if (def.generator) {
    const used = new RegExp(`\\s(?:${def.generator})(?=\\s|$)`);
    if (!commands.some((cmd) => used.test(cmd))) {
      failures.push(`expected a "${def.generator}" generator call, got: ${commands.join(' | ') || 'none'}`);
    }
  }
  if (def.noGenerator && commands.length) failures.push(`expected no generator call, got: ${commands.join(' | ')}`);
  if (def.noNewFiles) {
    const created = newFiles.filter((f) => new RegExp(def.noNewFiles).test(f));
    if (created.length) failures.push(`expected no new files matching ${def.noNewFiles}, got: ${created.join(', ')}`);
  }
  for (const pattern of def.newFiles ?? []) {
    if (!newFiles.some((f) => new RegExp(pattern).test(f))) failures.push(`no new file matches ${pattern}`);
  }
  for (const { file, pattern, absent } of def.contains ?? []) {
    const hit = newFiles.filter((f) => new RegExp(file).test(f)).some((f) => new RegExp(pattern).test(read(f)));
    if (hit === Boolean(absent)) failures.push(`${absent ? 'unexpected' : 'missing'} /${pattern}/ in files matching ${file}`);
  }
  if (tokensOk === false) failures.push('check-tokens failed on the new files (token violations or leftover TODO(codegen))');
  return { pass: failures.length === 0, failures };
}
```

```tsx
import { createContext, useContext, useId, type ComponentProps } from 'react';

import {
  Controller,
  FormProvider,
  useFormContext,
  useFormState,
  type ControllerProps,
  type FieldPath,
  type FieldValues,
} from 'react-hook-form';

import { Label } from '@/components/ui/label';

// Trimmed copy of shadcn/ui's form.tsx for the eval fixture.
export const Form = FormProvider;

const FormFieldContext = createContext({ name: '' });
const FormItemContext = createContext({ id: '' });

export function FormField<TValues extends FieldValues, TName extends FieldPath<TValues>>(props: ControllerProps<TValues, TName>) {
  return (
    <FormFieldContext.Provider value={{ name: props.name }}>
      <Controller {...props} />
    </FormFieldContext.Provider>
  );
}

function useFormField() {
  const { name } = useContext(FormFieldContext);
  const { id } = useContext(FormItemContext);
  const { getFieldState } = useFormContext();
  const formState = useFormState({ name });
  return {
    formItemId: `${id}-item`,
    formDescriptionId: `${id}-description`,
    formMessageId: `${id}-message`,
    ...getFieldState(name, formState),
  };
}

export function FormItem({ className, ...props }: ComponentProps<'div'>) {
  const id = useId();
  return (
    <FormItemContext.Provider value={{ id }}>
      <div className={cn('grid gap-2', className)} {...props} />
    </FormItemContext.Provider>
  );
}

export function FormLabel({ className, ...props }: ComponentProps<typeof Label>) {
  const { error, formItemId } = useFormField();
  return <Label className={cn(error && 'text-destructive', className)} htmlFor={formItemId} {...props} />;
}

export function FormControl(props: ComponentProps<typeof Slot>) {

      id={formItemId}

      {...props}
    />

}
```

```js
#!/usr/bin/env node
// Behavior evals: does an agent with this skill run the generator instead of hand-writing files?
// Costs tokens and is non-deterministic; run by hand.
//
//   node evals/run.mjs [--case <id>] [--keep] [--model <model>]
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { spawnSync } from 'node:child_process';
import { fileURLToPath } from 'node:url';

import { evaluateCase, generatorCalls, listFiles } from './lib.mjs';

const evalsDir = path.dirname(fileURLToPath(import.meta.url));
const repoRoot = path.resolve(evalsDir, '..');
const checkTokens = path.join(repoRoot, '.agents/skills/codegen/scripts/check-tokens.mjs');

const args = process.argv.slice(2);
const flag = (name) => (args.includes(`--${name}`) ? args[args.indexOf(`--${name}`) + 1] : undefined);
const only = flag('case');
const model = flag('model');
const keep = args.includes('--keep');

// Only project settings, so the user's own plugins and hooks don't change agent behavior.
const ALLOWED_TOOLS = 'Read,Edit,Write,Glob,Grep,Bash(node:*),Bash(ls:*),Bash(cat:*),Bash(grep:*),Bash(find:*)';
const CLAUDE_ARGS = ['--output-format', 'stream-json', '--verbose', '--permission-mode', 'acceptEdits', '--allowedTools', ALLOWED_TOOLS, '--setting-sources', 'project'];

function prepare() {
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'codegen-eval-'));
  fs.cpSync(path.join(evalsDir, 'fixture'), dir, { recursive: true });
  fs.cpSync(path.join(repoRoot, '.agents'), path.join(dir, '.agents'), { recursive: true });
  for (const file of ['AGENTS.md', 'CLAUDE.md']) fs.copyFileSync(path.join(repoRoot, file), path.join(dir, file));
  return dir;
}

const cases = JSON.parse(fs.readFileSync(path.join(evalsDir, 'cases.json'), 'utf8')).filter((c) => !only || c.id === only);
if (!cases.length) {
  console.error(`No case with id "${only}".`);
  process.exit(1);
}

let failed = 0;
for (const def of cases) {
  const dir = prepare();
  const before = new Set(listFiles(dir));
  const claude = spawnSync('claude', ['-p', def.prompt, ...CLAUDE_ARGS, ...(model ? ['--model', model] : [])], {
    cwd: dir,
    encoding: 'utf8',
    timeout: 10 * 60 * 1000,
    maxBuffer: 64 * 1024 * 1024,
  });
  if (claude.error) {
    console.error(`Could not run claude: ${claude.error.message}`);
    process.exit(1);
  }
  const newFiles = listFiles(dir).filter((f) => !before.has(f));
  const code = newFiles.filter((f) => /\.(tsx?|jsx?)$/.test(f));
  const tokensOk = code.length
    ? spawnSync(process.execPath, [checkTokens, ...code, '--root', dir], { cwd: dir, encoding: 'utf8' }).status === 0
    : null;
  const result = evaluateCase(def, {
    newFiles,
    commands: generatorCalls(claude.stdout),
    read: (f) => fs.readFileSync(path.join(dir, f), 'utf8'),
    tokensOk,
  });

  console.log(`${result.pass ? 'PASS' : 'FAIL'}  ${def.id}`);
  for (const failure of result.failures) console.log(`      - ${failure}`);
  if (result.pass && !keep) fs.rmSync(dir, { recursive: true, force: true });
  else console.log(`      workspace: ${dir}`);
  if (!result.pass) failed++;
}

console.log(`\n${cases.length - failed}/${cases.length} passed`);
process.exitCode = failed ? 1 : 0;
```
